# Salvo 海战齐射

10×10 海战棋变体：每轮双方按**各自存活舰船数同时开火**，舰船越少火力越弱，翻盘永远可能。

## 玩法

- 10×10 棋盘，双方各 5 艘舰船（航母 5 格、战列舰 4 格、巡洋舰 3 格、护卫舰 3 格、驱逐舰 2 格）。
- 每轮双方同时开火，开火数 = 己方当前未沉舰船数（开局 5 发，沉一艘少一发）。
- 炮弹同时结算：本轮被击沉的一方，炮弹照样打出。
- 先击沉对方全部舰船者胜；同轮互沉判和棋。

## 用法

```bash
python3 -m salvo                      # 人机对战（你是甲，AI 是乙）
python3 -m salvo --auto               # AI 自动对局演示（10 局）
python3 -m salvo --auto --games 20 --seed 7 --verbose
```

人机对战时每轮输入坐标，空格分隔，如 `a1 b3 c5`；输入 `q` 退出。
坐标格式 `a1`–`j10`（列 a–j，行 1–10）。

## AI 说明

hunt-target 策略：命中后追踪相邻四格，未命中时按黑白格奇偶搜索（小船必占黑白格）。
AI 只做单轮决策，不做概率密度建模。

## 已知局限

- AI 只是 hunt-target 单轮启发式，不做贝叶斯概率建模，懂行的玩家通常能赢
- 开局布放为随机（人机对战不可手动摆船）
- 文本界面，无图形/动画/存档/悔棋/网络对战
- Python 3.10+，纯标准库
